Fitted ML Architecture

Trained on 100,000 patient records using scikit-learn LogisticRegression(penalty='l2', max_iter=1000). Evaluates 15 one-hot encoded and continuous clinical features.

Dual-Modality Cloud Pipeline

Combines manual clinical entry with real-time wearable sensor streaming via a decoupled SensorAdapter. All ML inference is executed strictly on the Python FastAPI backend.

Medical Limitations

Probability output reflects uncalibrated logistic sigmoid scores. Not a diagnostic tool or clinical risk calculator. Intended solely for machine learning research.
